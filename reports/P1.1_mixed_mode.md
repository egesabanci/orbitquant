# P1.1 / P1.7 / P1.8 — Mixed Mode, Analytical Debiasing, Norm-Preserving Reconstruction

**Status:** Implemented and benchmarked (pure NumPy, no model/GPU).
**Files:** `baseline/corrections.py`, `baseline/run_corrections.py`
**Run:** `python3 -m baseline.run_corrections --d 64 --nrot 2000 --b 1`

## Purpose

These are cheap post-dequantization corrections that do not change the codebook
or bitstream:

- **P1.7 (debiased):** the MSE quantizer is biased for inner products (~2/π at
  b=1, paper Sec 3.2). A multiplicative correction factor (reciprocal of the
  measured bias ratio) makes the estimator unbiased.
- **P1.8 (norm_preserving):** renormalize the dequantized vector to the original
  norm before scoring, preserving the key norm that attention actually sees.
- **P1.1 (mixed):** the decision of which mode to use (plain MSE vs debiased vs
  product) is the mixed-mode policy. This benchmark measures the corrections so
  the policy can be chosen from measured bias/MSE, not assumed.

## Protocol

Fixed adversarial `x = e_1`, fixed `y = all_equal` (nonzero dot), averaged over
`n_rot` independent Haar-QR rotations. For each mode, report the inner-product
bias ratio `E[⟨y,Q(x)⟩]/⟨y,x⟩` (1.0 = unbiased) and per-vector MSE.

## Results — d=64, nrot=2000, b=1

```
  plain MSE bias ratio: 0.6306 (2/pi=0.6366)
  debias correction: 1.5858

mode              bias_ratio       mse unbiased?
mse                   0.6306    0.3587     False
debiased              1.0128    0.5794      True
norm_preserving       0.7997    0.3965     False
```

## Results — d=128, nrot=2000, b=1

```
  plain MSE bias ratio: 0.6249 (2/pi=0.6366)
  debias correction: 1.6003

mode              bias_ratio       mse unbiased?
mse                   0.6249    0.3610     False
debiased              1.0367    0.5938      True
norm_preserving       0.7683    0.4007     False
```

## Findings

1. **Plain MSE is biased** (bias ~0.63 ≈ 2/π), confirming the paper's Sec 3.2
   claim. MSE is low (0.36) but the inner-product estimate is systematically
   shrunk by ~37%.

2. **Debiasing (P1.7) achieves unbiasedness** (bias ~1.01, within noise of 1.0)
   at the cost of higher MSE (0.58 vs 0.36). The multiplicative correction
   fixes the bias but scales up the reconstruction error. This is the expected
   tradeoff: unbiased inner products come at the price of worse MSE. This makes
   debiasing a cheap alternative to residual QJL when unbiased scores matter
   more than raw reconstruction.

3. **Norm-preserving (P1.8) partially corrects bias** (0.80 vs 0.63) at slightly
   higher MSE (0.40 vs 0.36). It does not fully remove the bias (the norm is
   preserved but the direction is still shrunk), but it improves the score
   estimate at minimal MSE cost. This matches the proposal's stated tradeoff:
   renormalization can slightly worsen raw coordinate MSE while improving
   logits by preserving the key norm.

4. **Mixed mode (P1.1) is the policy choice.** The measured bias/MSE per mode
   lets a deployment choose: plain MSE where bias is tolerable (cheapest),
   debiased where unbiased scores are required (P1.7), or norm-preserving where
   a small bias fix is enough at minimal cost (P1.8). The full product estimator
   (residual QJL) is the most expensive option and only needed when debiasing
   is insufficient.

## Implications

- P1.7 is a viable cheap correction for the inner-product bias, validated at
  both d=64 and d=128.
- P1.8 provides a minimal-cost partial fix, useful where the key norm matters
  for attention.
- The mixed-mode policy (P1.1) can be driven by these measured values rather
  than by assumptions about outlier presence.
