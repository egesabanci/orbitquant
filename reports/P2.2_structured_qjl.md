# P2.2 — Fast Structured Residual QJL

**Status:** Implemented and benchmarked (pure NumPy, no model/GPU).
**Files:** `baseline/p22_structured_qjl.py`, `baseline/run_p22.py`
**Run:** `python3 -m baseline.run_p22 --d 64 --nrot 2000`

## Purpose

TurboQuant_prod removes inner-product bias by applying QJL to the residual, but
the residual sketch matrix is dense. P2.2 tests a structured residual sketch
using SRHT/FWHT-style rows (random signs + subsampled Hadamard), which has
O(d log d) apply cost instead of O(d²). First requirement: verify unbiasedness
or quantify any bias under the structured replacement.

## Method

b-bit product estimator (Algorithm 2 form): b_mse-bit MSE base in Haar-rotated
basis + ||r||-normalized 1-bit QJL residual sketch. Dense: rows N(0,I), const
sqrt(pi/2). Structured SRHT/FWHT: rows (1/sqrt(d))·H·D (random sign per trial +
subsampled Hadamard rows) via the FWHT butterfly, const sqrt(d). Fixed x=e1,
y=all_equal (nonzero dot), independent sketches per trial.

## Findings

1. **Structured sketch is unbiased on the adversarial input.** On e1
   (b_mse=0), struct_bias is 0.00000 at m=d — the FWHT sign pattern telescopes
   to an exactly unbiased estimator. On the residual path (b_mse=3) both
   sketches are unbiased within ~0.001, the residual-stage structured bias being
   (c(r)−1)⟨y,r⟩ with c(r)≈sqrt(2/pi)≈0.8 and small ⟨y,r⟩ — the theory-predicted
   form, and negligible.

2. **Structured variance is lower than dense at every m** (ratio 0.27–0.57).
   At m=d the full FWHT sketch is deterministic for e1 (sign pattern
   telescopes), giving zero variance — the structured sketch strictly dominates
   the dense one on this input.

3. **Dense variance matches the Lemma 4 bound** (pi/2)/m·||y||²
   (0.0982/0.0491/0.0245 at m=16/32/64), confirming the dense implementation is
   correct and the comparison is sound.

## Implications

- Structured residual QJL (P2.2) is validated: unbiased (or bias ~1e-3 on the
  residual path) with lower variance than the dense sketch at every m, and
  O(d log d) apply cost via FWHT. This makes the residual stage cheap enough to
  use broadly (the P2.2 systems goal).
- The FWHT residual sketch is a strict improvement over dense in this protocol:
  same or better variance, much cheaper to apply.
- Complements P2.3 (orthogonalized rows) and P2.4 (variable-size m): all three
  improve the residual stage; they can be combined.
