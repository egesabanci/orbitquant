# P2.10 — Predictive Residual KV Coding

**Status:** Implemented and benchmarked (pure NumPy, no model/GPU).
**Files:** `baseline/p210_predictive.py`, `baseline/run_p210.py`
**Run:** `python3 -m baseline.run_p210 --d 64 --nrot 2000`

## Purpose

Train compact linear predictors that reconstruct the current layer's keys from
previous-layer reconstructed keys (AQUA-KV: inter-layer KV dependencies make
residuals substantially easier to quantize). Store and quantize only the
residual. The first test is offline calibration with fixed predictors, no online
adaptation, and strict accounting for predictor weights and decode-time
arithmetic.

## Method

Synthetic correlated layer chain: Markov with rho=0.9, start e1, fixed
isometry, 12 layers. Calibration on the first 8 layers using directly-quantized
previous reconstructions; test on layers 8-11 (never seen in training). Two
predictors:
- scalar: per-coordinate linear predictor (64 b total, 0.08 b/coord amortized);
- rank1: rank-1 matrix predictor (8256 b total, 10.75 b/coord).

Residual quantized via the protocol (Haar rotation + exact-Beta Lloyd-Max)
rescaled by the exact norm header (cf. P1.3).

## Results — d=64, nrot=2000, rho=0.9, nlayers=12, seed=0

```
b=1:
  direct quantization MSE (current key alone):  0.358372
  predictive (scalar) MSE: 0.090177   = 0.252x direct   residual energy 0.2515
  predictive (rank1) MSE: 0.143492   = 0.400x direct   residual energy 0.4009

b=2:
  direct quantization MSE (current key alone):  0.114199
  predictive (scalar) MSE: 0.022316   = 0.195x direct   residual energy 0.1956
  predictive (rank1) MSE: 0.026928   = 0.236x direct   residual energy 0.2354
```

## Findings

1. **Predictive residual coding gives a 4-5x MSE reduction** at b=2 (0.022 vs
   0.114 direct) and b=1 (0.090 vs 0.358 direct). The predictive MSE equals
   residual-energy × direct-MSE exactly (verified: 0.2515×0.3584 = 0.0902) —
   the mechanism is clean: predicting removes the predictable component, and
   only the residual energy is quantized.

2. **The scalar predictor (0.08 b/coord amortized) beats the rank-1 predictor
   (10.75 b/coord) on this model.** The scalar is the optimal linear predictor
   for the isotropic Markov chain; the rank-1's much larger parameter cost buys
   nothing here. On real KV tensors with cross-coordinate structure, the rank-1
   (or higher-rank) predictor may win — needs P0.4 data.

3. **Works out-of-sample:** calibration on layers 0-7, tested on layers 8-11
   (never seen), with the residual-energy prediction holding. Robust across
   seeds (seed 7, rho=0.8, ncal=2 also verified).

## Implications

- Predictive residual coding (P2.10) is validated: 4-5x MSE reduction on
  correlated layer chains with a tiny (0.08 b/coord) scalar predictor. This
  matches AQUA-KV's core claim that inter-layer residuals are easier to
  quantize.
- The predictor cost is accounted (0.08 b/coord scalar amortized) — P0.5
  friendly; the rank-1 predictor's cost (10.75 b/coord) shows the accounting
  discipline matters: it loses despite better expressiveness.
- Composable: the residual codec is the standard TurboQuant path, so predictive
  coding stacks with P2.7 (clipping), P2.2/P2.3 (structured/orthogonal
  sketches), and OCTOPUS (P2.8) as the residual codec.
- Real KV cross-layer structure must be validated on a model (P0.4, GPU box).
